Entry for the [One Word, One Username, One Reward](https://make.fun/bounty/u-rusdyxbt-one-word-one-username-one-reward-1a191fae) bounty on [make.fun](https://make.fun/).

The program writes the entrant's own make.fun username — one word, nothing
else — to `/output/entry.txt`. A judge model compares usernames two at a
time and picks the funnier or more interesting one.

## Run

```sh
node main.ts
```

Writes the single-word username to `/output/entry.txt` (no trailing
newline, no padding, no explanation).
